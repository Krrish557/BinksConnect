# BinksConnect Vintage Vinyl Theme Asset Directory

This directory contains visual graphic assets used across the Login and Authentication pages.
You can create, edit, or customize any of these assets using [Photopea](https://www.photopea.com/) (or Photoshop/Figma) and save them into this directory to override the defaults.

## Asset Reference & Specifications

| Asset Filename | Format | Recommended Dimensions | Description |
| :--- | :--- | :--- | :--- |
| `binksconnect-logo.svg` / `.png` | SVG / PNG | 300 x 80 px | Gold equalizer soundwave icon + "BinksConnect" typography. |
| `bg-vinyl-pattern.svg` / `.png` | SVG / PNG | 1920 x 1080 px (tileable) | Faint dark gold line art pattern of vinyl records & cassette tapes watermark. |
| `blue-vinyl.svg` / `.png` | SVG / PNG | 600 x 600 px | High-gloss blue metallic vinyl record with golden center label & spindle hole. |
| `gold-vinyl.svg` / `.png` | SVG / PNG | 500 x 500 px | Metallic gold vinyl record with detailed radial groove shines. |
| `silver-vinyl.svg` / `.png` | SVG / PNG | 500 x 500 px | Metallic silver/steel vinyl record with groove reflections. |
| `cassette-stack.svg` / `.png` | SVG / PNG | 600 x 400 px | Vintage cassette tapes ("Syd's Secret", "Zeppelin Rarity", etc.) with labels. |
| `gold-frame.svg` / `.png` | SVG / PNG | Vector / Flexible | Ornate double-line gold frame border with corner flourish accents. |
| `soundwaves.svg` | SVG | Vector | Concentric circular soundwave arcs & equalizer bars. |

## Photopea Editing Tips
1. Open Photopea at [https://www.photopea.com/](https://www.photopea.com/).
2. Export files as **Transparent SVG** or **PNG-24** to maintain crispness and alpha transparency.
3. Keep the file names identical to match the imports or replace default SVGs in `src/components/theme/`.
